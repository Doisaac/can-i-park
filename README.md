# Can I Park?

**Can I Park?** es un sistema de disponibilidad de estacionamientos que busca permitir a los usuarios consultar cuántos espacios se encuentran disponibles antes de dirigirse al lugar.

## Objetivo

Mantener actualizada la disponibilidad del estacionamiento a partir de los movimientos de entrada y salida de vehículos.

Cada movimiento incluirá información como:

- Placa del vehículo.
- Tipo de movimiento: entrada o salida.

A partir de estos movimientos, el sistema actualizará la cantidad de espacios ocupados y disponibles.
